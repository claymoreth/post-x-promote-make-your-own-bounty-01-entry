## How to run

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` into the output directory. Replace the
placeholder URL in `POST.json` with the real posted status URL before
submitting.
